# 📊 Dashboard de Ventas de Supertienda – Power BI

Dashboard interactivo de análisis de ventas, ganancias y clientes, construido en **Power BI** a partir de un dataset de ventas comerciales.  
El objetivo del proyecto es mostrar habilidades de **análisis de datos** aplicadas a un caso realista de negocio.

![mundo](https://github.com/user-attachments/assets/10492bf2-2454-477d-b148-407455638295)

---

## 🧠 Objetivo del proyecto

- Analizar **ventas y ganancias** desde distintas perspectivas:
  - Temporal
  - Geográfica
  - Por categoría y subcategoría
  - Por cliente
- Construir un dashboard claro, interactivo y orientado a **toma de decisiones**.

---

## 📂 Dataset

- Dataset de ventas comerciales (formato CSV).
- Contiene información de:
  - Ventas
  - Ganancias
  - Clientes
  - Categorías y subcategorías
  - País, estado y región
  - Fechas de pedido

---

## 🧹 Limpieza y preparación de datos

Las siguientes transformaciones se realizaron en **Power Query**:

- Eliminación de filas con valores nulos en:
  - Ventas
  - Ganancias
  - Fechas
- Conversión de tipos de datos:
  - Fechas → Date
